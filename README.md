# Wolfgang Douglas website

Static informational website for wolfgangdouglas.info.

Publish using GitHub Pages from the main branch and repository root. The .nojekyll file keeps GitHub from processing the HTML with Jekyll.

After the initial site is published, add wolfgangdouglas.info in Settings → Pages → Custom domain before updating DNS at GoDaddy. Enable HTTPS when the certificate is ready.

The complete supplied background appears in background.html, with an untouched original text download. All images are included locally.
